# Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a crisp blue industry-network favicon that matches the app's research map identity without using an `AI` lettermark.

**Architecture:** Use one self-contained SVG file in Vite's `public/` directory and reference it from `index.html`. The SVG owns the visual design; the HTML owns browser discovery.

**Tech Stack:** Vite, static SVG, HTML favicon link.

---

### Task 2: Link Favicon In HTML

**Files:**
- Modify: `index.html`

- [ ] **Step 1: Keep the favicon link**

Add this line inside `<head>` after the viewport meta tag:

```html
<link rel="icon" type="image/svg+xml" href="/favicon.svg" />
```

- [ ] **Step 2: Verify the favicon reference**

Run: `rg -n 'rel="icon".*/favicon.svg' index.html`

Expected: one match in `index.html`.
